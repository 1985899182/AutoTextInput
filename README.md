## 介绍

本项目以学习交流为目的，一些作业需要码大量的文字，如果不能复制粘贴将会耗费大量时间，因此利用python强大的库，能够控制键盘实现快速录入。

## 特性

> 💡 支持英文
> 🔥 图形化界面
> ⚡ 含有打包好的应用，方便使用

## 快速使用


### 克隆项目
```bash
git clone https://github.com/1985899182/AutoTextInput.git
```

### 安装依赖
```bash
pip install pyautogui
```
